## 3. 玩家成长线与面板（本版新增）

- 声望 / 技能 / 资产三条各 **5 级**，带门槛与解锁：
  声望 0 / 3 / 15 / 40 / 90；技能 0 / **0.42** / 0.45 / 0.55 / 0.70；
  资产 0 / **600** / 900 / 1500 / 3000。
- “今天能做什么”面板：“先做这个” + 可接委托 / 可学技能 / 可拜访 NPC / 可买产业。
- 节奏：技能 L2 门槛 **0.36 → 0.42**、资产 L2 **400 → 600**；第 1 天从三线 L2 变为**单线 L2**，
  技能 / 资产改为**第 4 天到 L2**。
- **限制**：节奏调整只基于**单人实测路径**，未经多人 / 长时间验证；面板是只读派生，不改变世界状态。

## 4. 委托供给与过期修复（本版新增）

- 过期单自动下架；日界按模板补发，保证**每天至少 2 条可接**。
- 拒绝原因可诊断：`quest_expired` / `reputation_too_low` / `too_many_quests`。
- 7 天压力测试：**14 接 / 14 交 / 0 拒绝**（逐日可接 8/7/7/7/7/7/7）。
- **限制**：委托补发只在**玩家会话作用域**内生效；NPC 侧不发补发，NPC 委托仍可能因过期而减少。

## 5. 物价接入运行时（延续 p3i）

- 物价**只按日与库存变化**，不按小时、不按事件驱动；同一游戏日内不随对话/交易即时波动。
- 单日相对基准表最多 **±20%**（硬护栏）；2 日 **15 件商品中 12 件有非零价差**，最高 +12.5%。
- 价格会漂移：任何一次“事件数 / 金额 / 经济流量”对比都必须标注当前 `content_hash`
  （本版 `7ec670c1…`）与 `state_final` / `event_final` 哈希；跨快照不得直接相减。
