# 侠客行复刻 · xkx-parity

在 `world-sim` 引擎上复刻 `fluffos/xkx100` 杭州片区的文字世界。独立分支、独立内容包、独立端口。

| 项目 | 值 |
|---|---|
| 分支 | `xkx-parity`（核对基线 `70208d5`） |
| 内容 | 195 间房 / 105 位 NPC / 3 家商店 / 1 个门派 / 24 位师父 / 39 件物品 |
| 可玩命令 | 9 条动作命令 + `help`：`look` `go` `ask` `buy` `sell` `fight` `loot` `score` `inventory` |
| 测试 | 917 项（899 passed / 18 skipped / 0 failed） |
| Python | 3.10+；核对环境 3.12.7 |

> 这是 `xkx-parity` 分支的 README。`master` 上的九地点世界是另一个世界，入口和内容都不同。

---

## 1. 这是什么

- 复刻对象是 `fluffos/xkx100` 的杭州、石梁、嘉兴三个片区，以及原版的房间描述、NPC、商店和出口结构。
- 引擎部分共用 `master` 的事件溯源、单写者、确定性回放；内容部分完全独立，放在 `content/xkx/`。
- 玩家只需要浏览器。文字壳把 `look`、`go`、`fight` 这类命令翻译成引擎动作。
- 原版 MUD 还在本机 `127.0.0.1:4004` 跑着，只作对照，不参与本世界运行。

## 2. 快速开始

```bash
cd world-sim
git checkout xkx-parity
./scripts/start_world.sh --world xkx
```

启动后终端输出：

```text
内容包：<仓库>/content/xkx
世界：xkx.yaml  run=xkx-world
访问地址：http://127.0.0.1:8011
玩家 API：http://127.0.0.1:8041
日志：runs/xkx-world/logs/api.log
      runs/xkx-world/logs/ui.log
```

打开 <http://127.0.0.1:8011/>。

换端口：

```bash
./scripts/start_world.sh --world xkx --api-port 18041 --ui-port 18011
```

重建世界（清空 `runs/xkx-world`，重新载入内容）：

```bash
./scripts/start_world.sh --world xkx --reset
```

补充说明：

- 本世界 `auth: off`，打开页面直接进，不需要注册或口令。
- `ambient: 0`，没有后台 NPC 自走。
- 出生点是 `楼外楼`。角色首次进入发放 300 文、粗布×1、炊饼×3。
- 本次实测启动耗时（已有 run，未 `--reset`，16:21 重启计时）：API `/api/health` 返回 `ok=true` 用 **0.28s**，前端可访问用 **0.43s**。首次重建要重新载入内容，耗时会高于这两个数。

## 5. 核心机制

### 5.1 事件溯源

玩家的每条命令先变成动作意图，过前置条件，再由单写者按 tick 提交事件。状态从 `events.sqlite` 回放得到，不靠内存对象直接改。

### 5.2 同种子可复现

引擎只用 SplitMix64。相同种子、相同输入序列，回放出的房间、NPC、战斗结果一致。
战斗中的命中、伤害、闪避、架招都走固定公式，不调用 Python `random`。

### 5.3 复刻口径

- 房间描述、出口、NPC、商店货单来自 `content/xkx/*.json`。
- NPC 气血、攻击、防御等数值来自原版 LPC 数据的切片；`create()` 里的 `set_temp` 临时属性已抽取并接入战斗，切片内 34 位 NPC 共 78 条。
- 战斗公式在 `specs/xkx-parity/formula-map.md` 对照原版实现。
- 确定性测试：`tests/test_xkx_determinism_combat.py`、`test_xkx_determinism_spawn.py`、`test_xkx_determinism_legacy.py`、`test_xkx_formula_replay.py`。

## 8. 暂不可用

以下能力当前**没有开放**，不要写成已完成：

- **`climb` / `jump` 未实现。** 石梁夜明珠那条掉落实际拿不到。
- **原生掉落表只覆盖 3 个 NPC**：老虎、大狼狗、石梁的噬人鱼；105 位 NPC 里 102 位没有原生掉落。只看原生掉落表的话，约 95% 的 NPC 无掉落。
- **装备掉落已接入，但只对带装备的 NPC 生效。** 105 位 NPC 中 83 位带随身装备，死亡后装备落地（137 条装备引用全部可解析）；22 位无装备的 NPC 打死后地上仍是空的。
- **拜师学艺与 `learn` 未开放。** 24 位师父在内容里存在，但不能拜师、不能学技能；`score` 里门派一栏固定是“尚未拜入门派”。
- **装备加成与穿脱未开放。** `inventory` 只显示行囊与折卖价，穿装备不改变战斗数值。
- **PK 未开放。** `fight` 只对 NPC。
- **玩家主动 `drop` 未开放。** 只能 `loot` 捡地上的东西。
- **尸体容器不做。** 战斗结束不掉尸体包。
- **负重上限不做。** 捡多少都进背包。
- **师门任务不做。**
- **31 / 195 间房从出生点不可达。** 其中一部分与未实现的 `climb` / `jump` 有关。
- 文字壳只有 9 条命令；原版的 `skills`、`team`、`follow`、`emote` 等未接。
