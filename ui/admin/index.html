游戏参数

写入的是「期望值」；「当前运行值」只来自玩家进程观测。重启前不会变成已生效。

重启后生效流程：写入配置 → 生成 runs/<run>/admin_env.sh → 重启玩家 API → 管理服务观测到新 pid 后 effective_value 才更新、applied=true。
写入后立即读取仍是旧值、applied=false，这是刻意行为，不是失败。
