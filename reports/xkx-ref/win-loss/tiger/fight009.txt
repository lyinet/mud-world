
你对着老虎喝道：「直娘贼！明年今日就是你的忌日！」

> 你正盯着老虎的一举一动，随时准备发动攻势。

老虎跃起来用前掌往你的左肩猛地一拍！
结果在你的左肩造成一处瘀青。
( 你气喘嘘嘘，看起来状况并不太好。 )

老虎跃起来用前掌往你的左耳猛地一拍！
结果在你的左耳造成一处瘀青。
( 你似乎十分疲惫，看来需要好好休息了。 )

老虎扑上来张嘴往你的右肩狠狠地一咬！
结果造成轻微的咬伤！
( 你受了几处伤，不过似乎并不碍事。 )

老虎跃起来用前掌往你的右手猛地一拍！
结果一击命中，你的右手登时肿了一块老高！
( 你摇头晃脑、歪歪斜斜地站都站不稳，眼看就要倒在地上。 )

老虎举起爪子往你的两肋抓了过去！
结果在你两肋抓出一道细长血痕。
( 你受伤不轻，看起来状况并不太好。 )

你的眼前一黑，接着什么也不知道了....

【谣言】某人：我看到测试侠客被老虎杀死了。真是好惨。

你倒在地上，挣扎了几下就死了。

鬼门关 - 
    这里就是著名的阴间入口「鬼门关」，在你面前矗立著一座高大的
黑色城楼，许多亡魂正哭哭啼啼地列队前进，因为一进鬼门关就无法再
回阳间了。
    这里明显的出口是 south 和 north。
