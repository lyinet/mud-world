
你对着老虎喝道：「直娘贼！明年今日就是你的忌日！」

> 
老虎扑上来张嘴往你的右腿狠狠地一咬！
结果造成轻微的咬伤！
( 你似乎十分疲惫，看来需要好好休息了。 )

老虎跃起来用前掌往你的右耳猛地一拍！
结果在你的右耳造成一处瘀青。
( 你受伤不轻，看起来状况并不太好。 )

老虎跃起来用前掌往你的胸口猛地一拍！
结果在你的胸口造成一处瘀青。
( 你气息粗重，动作开始散乱，看来所受的伤着实不轻。 )

老虎跃起来用前掌往你的胸口猛地一拍！
结果在你的胸口造成一处瘀青。
( 你已经伤痕累累，正在勉力支撑着不倒下去。 )

老虎扑上来张嘴往你的两肋狠狠地一咬！
结果造成轻微的咬伤！
( 你已经伤痕累累，正在勉力支撑着不倒下去。 )
【存盘】您的档案已自动存盘。

老虎举起爪子往你的小腹抓了过去！
结果在你小腹抓出一道细长血痕。
( 你已经陷入半昏迷状态，随时都可能摔倒晕去。 )
【风闻】某人：“听说结婚后，在桃花村可以自己盖房生子，真是大妙！夫人，同去同去。”

你的眼前一黑，接着什么也不知道了....

【谣言】某人：我看到测试侠客被老虎杀死了。真是好惨。

你倒在地上，挣扎了几下就死了。
