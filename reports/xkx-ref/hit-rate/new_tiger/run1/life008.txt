
你对着老虎喝道：「直娘贼！今日不是你死就是我活！」

> 你注视着老虎的行动，企图寻找机会出手。

老虎举起爪子往你的颈部抓了过去！
结果只是轻轻地抓破你的皮肉。
( 你动作似乎开始有点不太灵光，但是仍然有条不紊。 )

老虎扑上来张嘴往你的右耳狠狠地一咬！
结果造成轻微的咬伤！
( 你气喘嘘嘘，看起来状况并不太好。 )

老虎举起爪子往你的腰间抓了过去！
结果在你腰间抓出一道细长血痕。
( 你似乎十分疲惫，看来需要好好休息了。 )

老虎扑上来张嘴往你的左手狠狠地一咬！
结果造成轻微的咬伤！
( 你受伤不轻，看起来状况并不太好。 )

老虎举起爪子往你的后心抓了过去！
结果在你后心抓出一道细长血痕。
( 你看起来已经力不从心了。 )

老虎扑上来张嘴往你的头顶狠狠地一咬！
结果造成轻微的咬伤！
( 你已经陷入半昏迷状态，随时都可能摔倒晕去。 )

老虎跃起来用前掌往你的右脚猛地一拍！
结果在你的右脚造成一处瘀青。
( 你受伤不轻，看起来状况并不太好。 )
【风闻】醉仙楼冼老板：“小店承办寿宴、婚宴、豪宴，有钱的大老爷二妹子们快快有请哪！”

你的眼前一黑，接着什么也不知道了....
