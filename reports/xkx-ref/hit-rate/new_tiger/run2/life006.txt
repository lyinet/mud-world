> 你慢慢地移动着脚步，伺机出手。

老虎跃起来用前掌往你的右脸猛地一拍！
结果在你的右脸造成一处瘀青。
( 你气喘嘘嘘，看起来状况并不太好。 )

老虎跃起来用前掌往你的左脸猛地一拍！
结果在你的左脸造成一处瘀青。
( 你似乎十分疲惫，看来需要好好休息了。 )

老虎扑上来张嘴往你的右脸狠狠地一咬！
结果只是勉强造成一处轻微咬伤！
( 你似乎十分疲惫，看来需要好好休息了。 )

老虎举起爪子往你的两肋抓了过去！
结果在你两肋抓出一道细长血痕。
( 你已经一副头重脚轻的模样，正在勉力支撑着不倒下去。 )

老虎跃起来用前掌往你的左臂猛地一拍！
结果在你的左臂造成一处瘀青。
( 你受了几处伤，不过似乎并不碍事。 )

( 你受了几处伤，不过似乎并不碍事。 )

老虎跃起来用前掌往你的胸口猛地一拍！
