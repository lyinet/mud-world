
你对着老虎喝道：「直娘贼！明年今日就是你的忌日！」

> 你注视着老虎的行动，企图寻找机会出手。

老虎举起爪子往你的右耳抓了过去！
结果在你右耳抓出一道细长血痕。
( 你受了几处伤，不过似乎并不碍事。 )

老虎跃起来用前掌往你的左腿猛地一拍！
结果在你的左腿造成一处瘀青。
( 你受伤不轻，看起来状况并不太好。 )

老虎举起爪子往你的左手抓了过去！
结果在你左手抓出一道细长血痕。
( 你似乎十分疲惫，看来需要好好休息了。 )

老虎扑上来张嘴往你的右脚狠狠地一咬！
结果造成轻微的咬伤！
( 你似乎十分疲惫，看来需要好好休息了。 )

老虎举起爪子往你的两肋抓了过去！
结果在你两肋抓出一道细长血痕。
( 你受伤不轻，看起来状况并不太好。 )

老虎跃起来用前掌往你的右手猛地一拍！
结果在你的右手造成一处瘀青。
( 你气息粗重，动作开始散乱，看来所受的伤着实不轻。 )

老虎扑上来张嘴往你的腰间狠狠地一咬！
结果造成轻微的咬伤！
( 你已经陷入半昏迷状态，随时都可能摔倒晕去。 )

你的眼前一黑，接着什么也不知道了....
