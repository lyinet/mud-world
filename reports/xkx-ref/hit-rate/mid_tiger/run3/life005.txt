
你对着老虎喝道：「直娘贼！明年今日就是你的忌日！」

> 你慢慢地移动着脚步，伺机出手。

老虎举起爪子往你的腰间抓了过去！
结果在你腰间抓出一道细长血痕。
( 你动作似乎开始有点不太灵光，但是仍然有条不紊。 )

老虎跃起来用前掌往你的右脸猛地一拍！
结果在你的右脸造成一处瘀青。
( 你气喘嘘嘘，看起来状况并不太好。 )

老虎举起爪子往你的头顶抓了过去！
结果在你头顶抓出一道细长血痕。
( 你受了几处伤，不过似乎并不碍事。 )

老虎跃起来用前掌往你的右腿猛地一拍！
结果在你的右腿造成一处瘀青。
( 你似乎十分疲惫，看来需要好好休息了。 )

老虎跃起来用前掌往你的左脚猛地一拍！
结果在你的左脚造成一处瘀青。
( 你受伤不轻，看起来状况并不太好。 )

老虎扑上来张嘴往你的左腿狠狠地一咬！
结果造成轻微的咬伤！
( 你摇头晃脑、歪歪斜斜地站都站不稳，眼看就要倒在地上。 )

老虎跃起来用前掌往你的左手猛地一拍！
结果只是轻轻地碰到，比拍苍蝇稍微重了点。
( 你摇头晃脑、歪歪斜斜地站都站不稳，眼看就要倒在地上。 )

老虎跃起来用前掌往你的后心猛地一拍！
结果在你的后心造成一处瘀青。
( 你已经陷入半昏迷状态，随时都可能摔倒晕去。 )
【风闻】洪七公：“丐帮是天下第一大帮会。探听江湖信息是本帮的拿手本事，本帮的密道穷极数代帮众之力，四通八达。”

你的眼前一黑，接着什么也不知道了....
