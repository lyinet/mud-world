
你对着老虎喝道：「直娘贼！明年今日就是你的忌日！」

> 你注视着老虎的行动，企图寻找机会出手。

老虎跃起来用前掌往你的左肩猛地一拍！
结果一击命中，你的左肩登时肿了一块老高！
( 你似乎十分疲惫，看来需要好好休息了。 )

老虎跃起来用前掌往你的小腹猛地一拍！
结果在你的小腹造成一处瘀青。
( 你已经一副头重脚轻的模样，正在勉力支撑着不倒下去。 )

老虎扑上来张嘴往你的小腹狠狠地一咬！
结果造成轻微的咬伤！
( 你受了几处伤，不过似乎并不碍事。 )

老虎扑上来张嘴往你的右手狠狠地一咬！
结果造成轻微的咬伤！
( 你已经陷入半昏迷状态，随时都可能摔倒晕去。 )

老虎跃起来用前掌往你的小腹猛地一拍！
结果一击命中，你的小腹登时肿了一块老高！
( 你已经陷入半昏迷状态，随时都可能摔倒晕去。 )

你的眼前一黑，接着什么也不知道了....
