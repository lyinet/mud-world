
你对着老虎喝道：「直娘贼！今日不是你死就是我活！」

> 你慢慢地移动着脚步，伺机出手。

老虎扑上来张嘴往你的颈部狠狠地一咬！
结果造成轻微的咬伤！
( 你受了几处伤，不过似乎并不碍事。 )

老虎举起爪子往你的右手抓了过去！
结果在你右手抓出一道细长血痕。
( 你气喘嘘嘘，看起来状况并不太好。 )

老虎跃起来用前掌往你的右手猛地一拍！
结果在你的右手造成一处瘀青。
( 你似乎十分疲惫，看来需要好好休息了。 )

老虎举起爪子往你的右脸抓了过去！
结果只是轻轻地抓破你的皮肉。
( 你已经一副头重脚轻的模样，正在勉力支撑着不倒下去。 )

老虎扑上来张嘴往你的左脸狠狠地一咬！
结果造成轻微的咬伤！
( 你看起来已经力不从心了。 )
【窗外】太阳开始从西方的天空中慢慢西沉。

老虎举起爪子往你的腰间抓了过去！
结果只是轻轻地抓破你的皮肉。
( 你摇头晃脑、歪歪斜斜地站都站不稳，眼看就要倒在地上。 )
【谣言】听说一年一度的华山论剑之少侠试剑马上就要举行了，不知道今年的第一是谁？

老虎跃起来用前掌往你的左耳猛地一拍！
结果只是轻轻地碰到，比拍苍蝇稍微重了点。
( 你摇头晃脑、歪歪斜斜地站都站不稳，眼看就要倒在地上。 )
【风闻】柳含翠：“想给心上人送朵花儿吗？维扬花店代办时鲜花卉。”

老虎跃起来用前掌往你的胸口猛地一拍！
结果在你的胸口造成一处瘀青。
( 你受伤不轻，看起来状况并不太好。 )

你的眼前一黑，接着什么也不知道了....

【谣言】某人：我看到测试侠客被老虎杀死了。真是好惨。

你倒在地上，挣扎了几下就死了。

鬼门关 - 
    这里就是著名的阴间入口「鬼门关」，在你面前矗立著一座高大的
黑色城楼，许多亡魂正哭哭啼啼地列队前进，因为一进鬼门关就无法再
回阳间了。
    这里明显的出口是 south 和 north。
