
你对着老虎喝道：「直娘贼！明年今日就是你的忌日！」

> 你目不转睛地盯着老虎的动作，寻找进攻的最佳时机。

老虎扑上来张嘴往你的左脸狠狠地一咬！
结果造成轻微的咬伤！
( 你气喘嘘嘘，看起来状况并不太好。 )
【窗外】夜晚降临了，远处的群山渐在你的视野里模糊了。
【官府通告】襄阳城中今夜有飞贼横行，良民百姓请闭门不出，切莫自误！

老虎扑上来张嘴往你的右脸狠狠地一咬！
结果造成轻微的咬伤！
( 你受伤不轻，看起来状况并不太好。 )

老虎举起爪子往你的两肋抓了过去！
结果在你两肋抓出一道细长血痕。
( 你似乎十分疲惫，看来需要好好休息了。 )

老虎扑上来张嘴往你的左臂狠狠地一咬！
结果造成轻微的咬伤！
( 你已经一副头重脚轻的模样，正在勉力支撑着不倒下去。 )

老虎跃起来用前掌往你的右臂猛地一拍！
结果在你的右臂造成一处瘀青。
( 你看起来已经力不从心了。 )

老虎举起爪子往你的右腿抓了过去！
结果在你右腿抓出一道细长血痕。
( 你摇头晃脑、歪歪斜斜地站都站不稳，眼看就要倒在地上。 )
【谣言】听说一年一度的华山论剑之少侠试剑马上就要举行了，不知道今年的第一是谁？

老虎跃起来用前掌往你的胸口猛地一拍！
结果在你的胸口造成一处瘀青。
( 你受伤不轻，看起来状况并不太好。 )
【风闻】某人：“听说结婚后，在桃花村可以自己盖房生子，真是大妙！夫人，同去同去。”

你的眼前一黑，接着什么也不知道了....

【谣言】某人：我看到测试侠客被老虎杀死了。真是好惨。

你倒在地上，挣扎了几下就死了。

鬼门关 - 
    这里就是著名的阴间入口「鬼门关」，在你面前矗立著一座高大的
黑色城楼，许多亡魂正哭哭啼啼地列队前进，因为一进鬼门关就无法再
回阳间了。
    这里明显的出口是 south 和 north。
