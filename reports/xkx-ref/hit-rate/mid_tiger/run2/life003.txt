
你对着老虎喝道：「直娘贼！明年今日就是你的忌日！」

> 你目不转睛地盯着老虎的动作，寻找进攻的最佳时机。

老虎跃起来用前掌往你的左脸猛地一拍！
结果只是轻轻地碰到，比拍苍蝇稍微重了点。
( 你动作似乎开始有点不太灵光，但是仍然有条不紊。 )

老虎扑上来张嘴往你的右手狠狠地一咬！
结果只是勉强造成一处轻微咬伤！
( 你看起来可能受了点轻伤。 )

老虎扑上来张嘴往你的颈部狠狠地一咬！
结果造成轻微的咬伤！
( 你受了几处伤，不过似乎并不碍事。 )

老虎跃起来用前掌往你的左臂猛地一拍！
结果只是轻轻地碰到，比拍苍蝇稍微重了点。
( 你似乎十分疲惫，看来需要好好休息了。 )

老虎扑上来张嘴往你的颈部狠狠地一咬！
结果造成轻微的咬伤！
( 你受伤不轻，看起来状况并不太好。 )

老虎举起爪子往你的头顶抓了过去！
结果在你头顶抓出一道细长血痕。
( 你受伤不轻，看起来状况并不太好。 )
【谣言】听说一年一度的华山论剑之少侠试剑马上就要举行了，不知道今年的第一是谁？

老虎举起爪子往你的右脸抓了过去！
结果在你右脸抓出一道细长血痕。
( 你摇头晃脑、歪歪斜斜地站都站不稳，眼看就要倒在地上。 )
【风闻】张无忌：“乾坤大挪移源自波斯。可化敌攻势于无形，或借势反击，以彼之力，制敌于飘逸之间，是天下一等一的腾挪功夫。”

老虎举起爪子往你的右耳抓了过去！
结果在你右耳抓出一道细长血痕。
( 你已经陷入半昏迷状态，随时都可能摔倒晕去。 )

老虎跃起来用前掌往你的腰间猛地一拍！
结果在你的腰间造成一处瘀青。
( 你气息粗重，动作开始散乱，看来所受的伤着实不轻。 )

你的眼前一黑，接着什么也不知道了....

【谣言】某人：我看到测试侠客被老虎杀死了。真是好惨。

你倒在地上，挣扎了几下就死了。

鬼门关 - 
    这里就是著名的阴间入口「鬼门关」，在你面前矗立著一座高大的
黑色城楼，许多亡魂正哭哭啼啼地列队前进，因为一进鬼门关就无法再
回阳间了。
    这里明显的出口是 south 和 north。
