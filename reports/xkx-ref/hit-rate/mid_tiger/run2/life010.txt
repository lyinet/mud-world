
你对着老虎喝道：「直娘贼！明年今日就是你的忌日！」

> 你目不转睛地盯着老虎的动作，寻找进攻的最佳时机。

老虎举起爪子往你的两肋抓了过去！
结果在你两肋抓出一道细长血痕。
( 你气喘嘘嘘，看起来状况并不太好。 )

老虎举起爪子往你的小腹抓了过去！
结果在你小腹抓出一道细长血痕。
( 你受伤不轻，看起来状况并不太好。 )

老虎扑上来张嘴往你的左腿狠狠地一咬！
结果造成轻微的咬伤！
( 你看起来已经力不从心了。 )

老虎扑上来张嘴往你的头顶狠狠地一咬！
结果造成一处咬伤！
( 你气息粗重，动作开始散乱，看来所受的伤着实不轻。 )

老虎扑上来张嘴往你的右臂狠狠地一咬！
结果造成一处咬伤！
( 你已经陷入半昏迷状态，随时都可能摔倒晕去。 )

你的眼前一黑，接着什么也不知道了....

【谣言】某人：我看到测试侠客被老虎击死了。真是好惨。

你倒在地上，挣扎了几下就死了。
