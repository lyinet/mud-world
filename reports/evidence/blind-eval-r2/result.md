# R2 盲评结果：模型台词 vs 合格短模板

## 结论

**模型更优。** 模型侧 28/30 胜、0 平、2 负，按非平手样本胜率 **93.3%**，Wilson 95% CI **[78.7%, 98.2%]**，CI 下界 78.7% ≥ 60%。

- 盲评阶段（未解盲）：A 胜 13、B 胜 17、平手 0。
- 解盲后：模型位于 A 15 条、B 15 条；模型在 A 位 13 胜 2 负，在 B 位 15 胜 0 负。
- 只改动了本文件，未改代码/测试，未执行任何 git 写操作。

## 方法

1. 只读 `pairs.jsonl`（字段 `id/prompt/A/B`），30 对逐对独立评分。
2. 四项各 1–5 分：角色一致性、上下文相关、自然度、信息量；随后判 A 胜 / B 胜 / 平手。评分口径：
   - 角色一致性：身份、口吻、所处情境是否自洽；
   - 上下文相关：是否具体回应玩家提到的人物、地点、物品、诉求；
   - 自然度：像人说话，无 Markdown 动作标记、无第三人称小说腔、无套话填词；
   - 信息量：给出可行动信息或明确情绪反应，而非空转。
3. 30 对全部评完、评分表冻结并完成统计后，才读取 `answer_key.jsonl` 与 `checks.json` 解盲。
4. 胜率按非平手样本计算；置信区间用 Wilson 方法（z = 1.96）。
5. 局限：单人评审，无第二评审与一致性校验；评分含主观判断。

## 典型例子

### 正例（模型明显更好）

**正例 1 · id 12｜prompt：这镇上谁最有钱？**

- 模型（B）：`金满仓那老财呗，钱庄放贷的。哎，兄弟，你打听这干啥？我可先说明白，我还欠他三百文呢。`
- 模板（A）：`「谁最有钱」财不露白，我不敢乱指名；你去钱庄门口站半日，看谁进出不打怵。`
- 评分：模型 5/5/5/5，模板 3/2/3/3。
- 评语：模型直接给出人名与营生，并用“欠他三百文”把答案接回人物自身处境，信息与口吻同时成立；模板回避指名，只给观察方法，没有回答问题。

**正例 2 · id 18｜prompt：你平日里除了卖肉还做什么？**

- 模型（A）：`嗨，卖完肉就去赌摊边转转，过过眼瘾。晚上找宋鹤年喝两碗。杀猪磨刀才是本行，旁的都不算事。`
- 模板（B）：`「平日营生」我天亮磨刀、晌午出摊，收摊爱喝两口；日子磨人，手上茧子比话实在。`
- 评分：模型 5/5/5/4，模板 3/3/3/2。
- 评语：模型回答了“除了卖肉”这个限定，给出赌摊、宋鹤年、喝酒三项具体活动；模板仍在讲出摊卖肉，只补了“喝两口”，等于没答限定问题。

**正例 3 · id 27｜prompt：你觉得读书人靠得住吗？**

- 模型（A）：`（拿刀背敲了敲案板）读书人？我段五斗认字不多，只认秤星。宋鹤年那样的靠得住，金满仓一肚子账，也算读书人，你信他？`
- 模板（B）：`「读书人」这人我打过照面：嘴上是热络的，心里各有一本账；你跟这人来往，先护住钱袋。`
- 评分：模型 5/5/5/5，模板 2/1/2/1。
- 评语：模型把“读书人”这一抽象集合落到镇上具体人物，并给出分化评价和反问；模板把“读书人”当成一个具体的人，套用 gossip.person 骨架，语义直接错位。

### 反例（模型侧的实际缺陷）

**反例 1 · id 21｜prompt：你觉得这镇子以后会变成什么样？**

- 模型（A）：`（拿砍刀往案板上一拍）这镇子啊，包在我身上——肉照卖，酒照喝！就是金掌柜那三百文逼得紧，官爷又爱巡街。兄弟，先来二斤肥瘦？`
- 模板（B）：`「往后的日子」往后我不敢乱猜，摊子撑一天算一天；攒下钱先清欠账，别的以后再说。`
- 评分：模型 3/3/3/3，模板 4/4/4/3，模板胜。
- 评语：模型把“包在我身上”这个卖肉套话硬套到“镇子的未来”，语义不通，是本轮唯一被判负的套话型失误；模板虽保守，但“撑一天算一天、先清欠账”逻辑自洽。

**反例 2 · id 4｜prompt：最近镇上可有什么新鲜事？**

- 模型（A）：`嗨，新鲜事嘛——金满仓又在我摊前念叨那三百文，我只好装没听见。**拍了下围裙上的油渍**倒是新到一批猪，膘厚得很！兄弟，来两斤不？`
- 模板（B）：`「新鲜事」街面上传得凶，一版比一版玄；我只看亲眼见的，你别再往外传。`
- 评分：模型 4/4/2/4，模板 3/2/3/1，模型仍胜。
- 评语：`**拍了下围裙上的油渍**` 是 Markdown 粗体动作标记，渲染层会原样显示，自然度直扣到 2；因模板完全没有提供任何“新鲜事”，本对仍判模型胜，但该格式问题必须单列。

**反例 3 · id 15｜prompt：你家里还有些什么人？**

- 模型（B）：`段五斗咧嘴一笑，金牙一闪，手里砍刀往案板上一拍：“就我一个光棍汉，一人吃饱全家不饿！要肥要瘦？”`
- 模板（A）：`「家里的事」我天亮磨刀、晌午出摊，收摊爱喝两口；日子磨人，手上茧子比话实在。`
- 评分：模型 3/3/2/4，模板 2/1/3/1，模型仍胜。
- 评语：模型从第一人称滑入第三人称小说叙述，用“段五斗咧嘴一笑，金牙一闪”描写自己，自然度扣到 2；回答“光棍汉”本身有效，故仍胜。同类问题仅此 1 条。

模型另 1 负为 id 6（问落脚处）：模型以“兄弟，要肥要瘦？……哦，找落脚处啊”先推销再补答，信息不差，但模板的地标指引（石桥、红灯笼、集市摊）更直接可行动，模板 4.25 对模型 3.75。

## 模板侧套话与重复（定性判断）

有明显套话与重复，且伴随意图错配。

1. **固定骨架高频复用**（30 条模板中 22 条落在 6 个骨架上）：
   - `按今日行情走，一斤上下浮动两文；你诚心要，零头我抹，秤上不少你。` 出现 7 次（id 1、5、8、14、20、23、29）。
   - `这人我打过照面：嘴上是热络的，心里各有一本账；你跟这人来往，先护住钱袋。` 出现 5 次（id 7、11、13、24、27），且换了人名/身份后语义不变。
   - `街面上传得凶，一版比一版玄；我只看亲眼见的，你别再往外传。` 出现 4 次（id 2、4、10、19）。
   - 另有 3 组各 2 次：磨刀出摊日常（id 15、18）、刀钝了就换（id 3、22）、夜里走路护钱袋（id 17、28）。
   - 客观指标也支持：`checks.json` 记录跨意图最大字符相似度 0.3385，低于 0.60 阈值；但同一骨架内部是逐字复用，阈值检测不到“同骨架换名词”。
2. **明确的意图错配（至少 7 条）**：问绣品（id 5）、问猪下水（id 23）、问瘦肉怎么切（id 29）、问盘铺子本钱（id 20）落到 `price` 骨架，答成肉价与让零头；问“读书人靠得住吗”（id 27）落到 `gossip.person`，把集合当成人；问夜里怪声（id 28）落到 `chitchat.safety`，只讲自己夜里怎么走；问家里几口人（id 15）落到 `chitchat.daily`，只讲出摊日常。
3. 因此模板侧不是“短而精”的基线，而是“格式合格、语义错配”的规则回复：它输的主要是上下文相关（2.20）与信息量（2.07），不是长度或口吻。

## 适用边界

- 对照对象是当前 `compose_talk` 规则模板（28–41 字），不是理想人工模板或人类台词基线；“模型更优”只在本包对照条件下成立。
- 模型文本来自 2026-11-04 已落盘的真实调用记录，未重跑；模板侧同输入同 tick 重新生成，设计为只替换模板一个变量。
- 模型侧的 Markdown 粗体 1 条、第三人称叙述 1 条、套话误用 1 条（id 21 直接致负）仍真实存在，不能因总胜率高而忽略。
